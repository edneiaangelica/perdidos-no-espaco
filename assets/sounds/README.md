# Sons do Jogo — Arquivos Necessários

Adicione os seguintes arquivos `.mp3` nesta pasta para ativar o áudio do jogo:

| Arquivo              | Descrição                                      |
|----------------------|------------------------------------------------|
| `musica.mp3`         | Música de fundo em loop (instrumental/espacial)|
| `acerto.mp3`         | Som de resposta correta                         |
| `erro.mp3`           | Som de resposta incorreta                       |
| `tempo-esgotado.mp3` | Som de tempo esgotado                          |
| `vitoria-final.mp3`  | Som da vitória final (missão cumprida)          |
| `derrota-final.mp3`  | Som da derrota final (missão falhou)            |

> **Observação:** O jogo funciona normalmente sem esses arquivos — o áudio é opcional.
> Os botões de som e tela cheia ficam visíveis no canto superior direito da tela.
