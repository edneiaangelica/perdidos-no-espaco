# perdidos-no-espaco
Jogo pedagógico de matemática para crianças do Ensino Fundamental.

## Como executar
Abra `index.html` no navegador ou rode um servidor estático:

```bash
python3 -m http.server 4173
```

Depois acesse `http://127.0.0.1:4173/index.html`.

## Assets
Coloque as imagens em `assets/images` e os sons em `assets/sounds`.

Imagens esperadas (PNG):
- tela-inicial
- narrativa-1 até narrativa-7
- nivel1-vitoria, nivel1-derrota
- nivel2-vitoria, nivel2-derrota
- nivel3-vitoria, nivel3-derrota
- pistas
- vitoria-final, derrota-final
- acerto, erro, tempo-esgotado

Sons esperados (MP3):
- acerto
- erro
- tempo-esgotado
- vitoria-final
